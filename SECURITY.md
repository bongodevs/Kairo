# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.8.x   | :white_check_mark: |
| < 4.8   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Kairo, please do not open a public issue.

Instead, please report security issues responsibly:
- Email the maintainers or report via private GitHub Security Advisory at `https://github.com/bongodevs/Kairo/security/advisories/new`.
- Please include steps to reproduce the issue, along with relevant logs, environment details, or minimal reproduction scripts.

We will acknowledge receipt within 48 hours and work with you to coordinate a patch and release before public disclosure.
